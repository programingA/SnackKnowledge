# 📕 한입지식 | SnackKnowledge

> 검색해서 배우는 것이 아니라, 발견하면서 배운다.

**한입지식**은 다양한 분야의 흥미로운 지식을 짧고 쉽게 접하고, AI와의 질문·퀴즈·설명 활동으로 이해를 넓히는 지식 탐색 서비스입니다.

무엇을 검색해야 할지 몰라도 카드 피드에서 새로운 주제를 발견하고, 궁금한 점을 질문하거나 자신의 말로 설명하며 학습할 수 있도록 기획했습니다.

## 프로젝트 현황

**2026년 10월 28일 기준 기획 단계**입니다. 현재 로컬 프로젝트에는 React + Vite 초기 구성이 있으며, 서비스 화면·백엔드·데이터베이스·AI 연동은 아직 구현되지 않았습니다. 아래 기능과 구조는 개발 목표입니다.

- 개발 시작 예정: **2026년 11월 2일**
- 최종 발표 예정: **2026년 11월 18일**
- 개발 시간 기준: 평일 하루 약 2시간
- 발표 목표: **지식 탐색 → AI 질문 → 퀴즈 → 직접 설명과 피드백**으로 이어지는 학습 흐름 시연

## 주요 기능 — 발표 버전 목표

| 기능 | 내용 |
| --- | --- |
| 카드형 지식 피드 | MySQL에 준비한 기본 지식을 카테고리·제목·짧은 요약으로 표시 |
| 지식 상세보기 | 선택한 카드의 전체 내용을 읽고 AI 학습 기능으로 이동 |
| AI 지식 생성 | 원하는 주제를 입력하면 제목·요약·본문으로 구성된 짧은 지식 생성 |
| AI 추가 질문 | 현재 읽고 있는 지식을 바탕으로 질문하고 설명·예시 확인 |
| AI 객관식 퀴즈 | 학습한 지식으로 문제를 생성하고, 답안 제출 후 정답·해설 확인 |
| 직접 설명하기 및 AI 피드백 | 사용자 설명을 원문과 비교해 잘 이해한 부분·수정할 부분·보충 설명 제공 |

### 학습 흐름

```text
카드 피드에서 지식 발견 / 원하는 주제로 AI 지식 생성
                        ↓
                   지식 상세보기
                        ↓
            AI에게 추가 질문하며 이해 확장
                        ↓
                객관식 퀴즈로 내용 확인
                        ↓
                 자신의 말로 직접 설명
                        ↓
             AI 피드백을 확인하고 다시 학습
```

## 기술 구성

| 영역 | 기술 | 역할 | 상태 |
| --- | --- | --- | --- |
| 프론트엔드 | React, JavaScript, Vite | 카드 피드와 AI 학습 화면 | 초기 구성 |
| 백엔드 | Java, Spring Boot | 지식 조회, AI 요청 처리, 퀴즈 채점 | 구현 예정 |
| 데이터베이스 | MySQL | 기본 지식 콘텐츠 및 퀴즈 정답 등 서비스 데이터 저장 | 구현 예정 |
| 생성형 AI | OpenAI API | 지식 생성, 질문 응답, 퀴즈 생성, 설명 피드백 | 연동 예정 |

### 시스템 구조 — 설계안

```text
사용자
  ↕
React
  ↕ API 요청 / 응답
Spring Boot
  ├── MySQL: 지식 조회 및 서비스 데이터 저장
  └── OpenAI API: 지식 생성·질문·퀴즈·피드백
```

AI 요청은 Spring Boot 서버에서 처리하도록 설계합니다. API 키는 서버 환경변수로 관리하고, 프론트엔드 코드나 저장소에 포함하지 않습니다.

## UI/UX 방향

**따뜻한 색감의 깔끔한 카드 피드와 생동감 있는 상호작용**을 목표로 합니다.

- 밝은 크림색 배경과 살구색·코랄색 포인트를 활용합니다.
- 이미지는 추후 검토하고, 우선 카테고리·제목·요약 중심의 텍스트 카드를 구성합니다.
- 충분한 여백과 둥근 모서리로 읽기 편한 화면을 만듭니다.
- 카드 등장·호버, AI 로딩, 퀴즈 및 피드백 결과 표시에 애니메이션을 적용합니다.
- 모바일 화면에 대응하고, 움직임 줄이기 설정에서는 애니메이션을 축소합니다.

## 콘텐츠 및 AI 처리 기준

- 기본 피드는 사전에 준비하고 검토한 지식을 사용합니다.
- 발표 버전에서 AI 생성 결과는 현재 화면에서 확인하고 학습하는 범위로 제공합니다.
- AI 생성 지식은 공용 피드에 자동 공개하지 않으며, 공용 콘텐츠 등록 전 별도 검토를 거치도록 합니다.
- 퀴즈와 설명 피드백은 학습한 지식 원문을 기준으로 생성합니다.
- 퀴즈는 서버에서 정답을 비교해 채점하고, 제출 후 정답과 해설을 표시하도록 설계합니다.
- AI 피드백은 이해를 돕는 학습 참고 자료로 제공합니다.
- AI 요청 중에는 진행 상태를 표시하고, 실패 시 안내와 재시도 수단을 제공합니다.

- 개인 맞춤 추천

- 복잡한 스크롤 연출 및 추천 알고리즘 고도화

## 로컬 실행 — 현재 프론트엔드

Node.js와 npm이 설치된 환경에서, `package.json`이 있는 프로젝트 루트에서 실행합니다. 아래 명령은 프론트엔드 코드가 포함된 로컬 작업 폴더 기준입니다.

```bash
npm ci
npm run dev
```

터미널에 표시되는 로컬 주소로 접속합니다. 현재는 초기 구성 상태이므로 서비스 기능은 제공되지 않습니다.

| 명령 | 용도 |
| --- | --- |
| `npm run build` | 프로덕션 빌드 |
| `npm run preview` | 빌드 결과 로컬 미리보기 |
| `npm run lint` | 코드 정적 검사 |

백엔드 실행 방법, Java 버전, MySQL 연결 설정 및 AI 환경변수 이름은 구현 후 추가할 예정입니다.
